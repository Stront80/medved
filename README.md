# Нападение медведя · 1.0

Браузерная аркада: 75 секунд через тёмный лес до укрытия. Страшный медведь, три дорожки, музыка и звуковые эффекты, русский и английский языки. **YaCo 2026.**

## Запуск

Самый простой вариант — открыть `index.html` в современном браузере. Все скрипты, стили и рисунки локальные; установка пакетов не нужна. Прямое открытие файла не проверено браузерным инструментом, проверен HTTP-запуск:

```bash
python3 -m http.server 8773 --bind 127.0.0.1 --directory .
```

Команду запускайте из корня клонированного репозитория `medved`, где находится index.html. Затем откройте **http://127.0.0.1:8773**. Остановка сервера — Ctrl+C. При запуске из другого каталога замените точку после `--directory` полным путём к папке игры в кавычках. Если видите «Directory listing», сервер запущен из папки без index.html.

Этот адрес доступен на компьютере запуска. Для просмотра на смартфоне/планшете потребуется передать папку на устройство с поддержкой локального HTML либо отдельно согласовать размещение. Игра адаптирована под мобильные экраны; публикация и доступ по сети не настроены.

## Как играть

Нажмите «Бежать». Герой бежит сам. Обходите камни и поваленные деревья, меняя дорожку свайпами или кнопками «Влево»/«Вправо». На клавиатуре — стрелки или A/D. Один жест меняет одну дорожку, переход занимает 150 мс. Первые пять секунд безопасны.

Начальная дистанция до медведя — 100. Каждый удар отнимает 40, чистый бег восстанавливает 2 в секунду до 100. При нуле медведь догоняет героя. После удара — секунда защиты от повторного столкновения. Каждый ряд оставляет свободную дорожку и виден примерно за 2.8 секунды до столкновения. До укрытия — 75 секунд игрового времени; победа сохраняет минимальное число столкновений как рекорд.

Кнопка паузы, Escape или P останавливает забег. Настройки звука тоже ставят игру на паузу. Скрытие вкладки, смена ориентации или большой провал времени останавливают игру; продолжение — нажатием. Перезапуск сбрасывает маршрут и дистанцию. Незаконченный забег не сохраняется.

## Язык, музыка и данные

RU/EN переключается в меню или шапке; во время диалога используйте переключатель внутри него. По умолчанию русский для русскоязычного браузера, иначе английский. Все игровые тексты переведены.

Оригинальная синтезируемая тема 96 BPM, шаги, рычание, манёвр, столкновение и финал. Аудио начинается после действия пользователя. Музыка и эффекты выключаются отдельно; есть общая громкость. На паузе источники останавливаются. Нельзя гарантировать звук при системном запрете воспроизведения; игра показывает уведомление и продолжает работать.

В localStorage ключ `bear-attack-v1` хранит только язык, настройки звука и рекорд этого браузера. Очистка данных удаляет рекорд, синхронизации нет. При недоступном хранилище всё работает до закрытия страницы. Регистрации, внешних ресурсов, аналитики и сетевого режима нет. Графика создана локальным Canvas-кодом, звуки — Web Audio без сторонних записей.

## Проверки

```bash
node tests/engine.test.cjs
```

Восемь тестов: игровые состояния, движение, столкновения, защита, победа/поражение, 200 трасс с прохождением без ударов и 30000 случайных команд. Установка зависимостей не нужна.

[Фактические браузерные и аудиопроверки](проверки.md). Физические устройства, Safari/Firefox и субъективное прослушивание ещё не проверены. Следующий шаг — попробовать игру и сообщить, подходят ли сложность, образ медведя и звук.

## Файлы

`engine.js` — игровая модель; `renderer.js` — рисование; `audio.js` — синтез; `app.js` — интерфейс, ввод, переводы и хранение; `style.css`/`index.html` — оформление и разметка. Логика не содержит производственных тестовых переключателей: сценарии браузерной проверки внедрялись только инструментом в отдельные сеансы.
