# Архитектура 1.0

Дата: 2026-11-25. Fullstack разработчик, TASK-061. DEC-035 согласовано.

Классические локальные скрипты, совместимые с file://, без импортов/зависимостей. engine.js — модель с фиксированным шагом 1/60 с, команды движения, генератор препятствий с внедряемым RNG; renderer.js — Canvas; audio.js — Web Audio; app.js — ввод, локализация, диалог и хранение. Серверного API нет. Node built-in test проверяет модель через CommonJS.

Ряд препятствий оставляет одну или две свободные дорожки. Интервал рядов ≥1.25 с, подход 2.8 с, движение через две дорожки ≤0.3 с; любой ряд достижим из любого предыдущего свободного положения. Столкновение проверяется один раз на пересечении линии игрока; при смене дорожки используется фактическая интерполированная позиция, а не будущая цель. Удар распространяется на весь ряд, чтобы не списать дважды. Логический шаг не зависит от частоты отрисовки. Большой провал времени вызывает паузу, а не мгновенный проигрыш.

Один requestAnimationFrame, один планировщик музыки; повторный старт очищает состояние. Музыка создаётся жестом и звучит только в активном забеге. При закрытом диалоге и возврате во вкладку автоматического продолжения нет. Данные bear-attack-v1: язык, каналы, громкость, лучший результат (минимум столкновений); валидируются, ошибки перехватываются. Внешних запросов нет.
