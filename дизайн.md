# Дизайн 1.0

Дата: 2026-11-25. Веб дизайнер, TASK-060. Вход — бриф/DEC-035, план утверждён пользователем.

Полноэкранная сцена, перспектива лесной тропы. Палитра: угольно-зелёный фон, сизый туман, янтарные акценты/глаза, молочный текст, красный только для опасной дистанции. Тёмный лес остаётся читаемым; камни серые, брёвна коричневые со светлым срезом. Персонаж в охристой куртке. Медведь виден снизу позади героя, с оскаленной пастью, клыками, ушами, когтями и рисованной шерстью. На старте крупная морда, в игре масштаб и положение отражают дистанцию.

Шапка: название, RU/EN, звук, пауза. Табло: прогресс до укрытия и дистанция. Низ: две крупные кнопки «Влево»/«Вправо», подсказка свайпа; YaCo 2026 всегда видимо. Стартовая карточка: название, описание угрозы, цель, правила, «Бежать». Пауза/настройки/финал — прокручиваемый диалог с видимым фокусом. При проигрыше плавное затемнение без резкого появления морды.

Вертикальный телефон — сцена между компактными панелями; горизонтальный экран — узкие верхняя и нижняя панели, диалог ограничен высотой и прокручивается. Планшет/десктоп — поле до 920 px, симметричные тёмные поля. Кнопки ≥48 px, подписи ≥14 px, основной текст ≥16 px. SVG-иконки с доступными названиями. Для reduced-motion убираются качание и частицы, механика движения остаётся.

Полная локализация, клавиатурный фокус, Escape/P для паузы; стрелки/A/D для бега. Звук: отдельные музыка/эффекты, общая громкость; кнопки доступны и при отказе API. Недоступное направление обозначается disabled. Вне игры управление выключено. Ошибка аудио/хранилища — спокойное сообщение.

Проверка реализации и ограничения — в проверки.md. Проверка роли проводится последовательно в том же сеансе, не является независимым пользовательским утверждением.
